
# نصب ابزارهای امنیتی BlackArch روی Zenora Linux

به مستندات رسمی **ابزارهای امنیتی BlackArch روی Zenora Linux** خوش آمدید. در این راهنما، نحوهٔ نصب و استفاده از ابزارهای امنیتی متنوع BlackArch و سایر توزیع‌های امنیتی روی Zenora Linux را خواهید آموخت.

---

## 📜 مقدمه

**BlackArch** یک پروژه منبع‌باز است که بیش از ۲۸۰۰ ابزار امنیت سایبری و تست نفوذ را ارائه می‌کند. زنورا لینوکس به صورت پیش‌فرض مخازن BlackArch را در خود دارد و آمادهٔ نصب این ابزارها به سادگی با pacman است.

ابزارها شامل دسته‌بندی‌های متنوعی مانند:

- ابزارهای جمع‌آوری اطلاعات
- تست شبکه، وب و API
- مهندسی معکوس و تحلیل بدافزار
- کرک رمزعبور و حملات بروت فورس
- مهندسی اجتماعی و اکسپلویت

---

## 🧰 نصب ابزارها

### نصب همه ابزارهای BlackArch (برای محیط‌های تخصصی):

```bash
sudo pacman -S blackarch
```

### نصب گروه خاصی از ابزارها (مثلاً ابزارهای وای‌فای):

```bash
sudo pacman -S blackarch-wireless
```

### مشاهده لیست گروه‌های موجود:

```bash
pacman -Sg | grep blackarch
```

---

## ⚡ نمونه ابزارهای پرکاربرد

| ابزار          | کاربرد                                |
| -------------- | ------------------------------------- |
| `nmap`         | اسکنر شبکه و پورت                     |
| `wireshark-qt` | تحلیلگر ترافیک شبکه                   |
| `aircrack-ng`  | حمله به WPA/WEP وای‌فای               |
| `hydra`        | حملات بروت‌فورس روی سرویس‌ها          |
| `metasploit`   | اکسپلویت و مدیریت نفوذ                |
| `sqlmap`       | شناسایی و سوءاستفاده از SQL Injection |

برای نصب هریک از ابزارها:

```bash
sudo pacman -S <tool-name>
```

مثال:

```bash
sudo pacman -S nmap hydra sqlmap
```

---

## 🖥️ اجرای ابزارها

ابزارها را با تایپ نام آن‌ها در ترمینال اجرا کنید. مثال:

```bash
nmap -sV 192.168.1.1
```

برای مشاهده راهنمای ابزار:

```bash
nmap -h
```

## 🚨 هشدار امنیتی

**استفاده از این ابزارها بدون اجازه روی سیستم یا شبکه‌ای که مالک آن نیستید غیرقانونی است.**

این ابزارها فقط برای اهداف آموزشی، تست امنیتی مجاز و محیط‌های آزمایشگاهی توصیه می‌شوند.

---

## 🧩 توصیه‌ها برای استفاده در Zenora

* از ترمینال‌های چندزبانه مثل wezterm یا kitty استفاده کنید.
* برای ابزارهایی مثل `wireshark` ممکن است نیاز به اجرای root یا تنظیم مجوزها باشد.
* بسته `dev-tools` را نصب کنید تا بتوانید ابزارهایی را از سورس بسازید.
