
به مستندات **نصب و پیکربندی yay** خوش آمدید. این راهنما به شما کمک می‌کند تا **yay**، یکی از محبوب‌ترین ابزارهای مدیریت بسته AUR را در سیستم zenora Linux خود نصب و پیکربندی کرده و از قابلیت‌های قدرتمند آن بهره ببرید.

---

## 📜 مرور کلی

**yay** (Yet Another Yaourt) یک دستیار مدیریت بسته مدرن و سبک برای zenora Linux است که امکان نصب، به‌روزرسانی و جستجوی بسته‌ها از **AUR (Arch User Repository)** را فراهم می‌کند.

ویژگی‌های اصلی **yay** عبارتند از:

- نصب همزمان بسته‌های رسمی و AUR  
- پشتیبانی کامل از عملیات `pacman`  
- رابط کاربری تعاملی، سریع و سبک  
- قابلیت کش کردن و دسته‌بندی بسته‌ها  
- پشتیبانی از auto-completion و history  

---

## 🔧 ویژگی‌ها

- **پشتیبانی کامل از AUR** بدون نیاز به ابزارهای اضافی  
- **تجربه‌ای مشابه pacman** با دستورات مشابه  
- **تعامل هوشمندانه** با کاربر در طول نصب و به‌روزرسانی  
- **جستجوی سریع** با قابلیت اولویت‌بندی نتایج  
- **امکان ویرایش PKGBUILD** قبل از نصب  
- **نصب خودکار وابستگی‌ها**  

---

## 🛠️ نصب

برای نصب yay به یکی از روش‌های زیر عمل کنید:

### نصب از طریق بسته‌های رسمی (اگر موجود باشد)

```bash
sudo pacman -S yay
````

> توجه: در برخی مخازن مانند `zenora` یا `archlinuxcn` این روش پشتیبانی می‌شود.

### نصب به‌صورت دستی از AUR

```bash
sudo pacman -S --needed base-devel git
cd /tmp
git clone https://aur.archlinux.org/yay.git
cd yay
makepkg -si
```

این روش مطمئن‌ترین راه برای نصب مستقیم آخرین نسخه **yay** از AUR است.

---

## ⚙️ تنظیمات اولیه

پس از نصب، می‌توانید با اجرای دستور زیر، yay را تست کرده و از رابط تعاملی آن استفاده کنید:

```bash
yay
```

اگر برای اولین بار اجرا شود، yay ممکن است از شما بپرسد که آیا می‌خواهید برخی تنظیمات را پیکربندی کنید یا نه. انتخاب پیش‌فرض معمولاً کافی است.

### پیشنهاد: غیرفعال‌سازی پرسش‌های تکراری

اگر می‌خواهید اجرای yay کمتر نیاز به تایید دستی داشته باشد، فایل تنظیمات زیر را ویرایش کنید:

```bash
nano ~/.config/yay/config.json
```

و تنظیمات زیر را اضافه یا اصلاح کنید:

```json
{
  "sudoloop": true,
  "answerclean": "All",
  "removemake": true
}
```

## 📋 استفاده

### نصب بسته‌ای از AUR:

```bash
yay -S <package-name>
```

مثال:

```bash
yay -S google-chrome
```

### به‌روزرسانی تمام بسته‌ها:

```bash
yay -Syu
```

### جستجو در بین بسته‌های رسمی و AUR:

```bash
yay <keyword>
```

### حذف بسته:

```bash
yay -Rns <package-name>
```

## 🛠️ رفع مشکلات

### ۱. **خطای مربوط به GPG**

در صورتی که هنگام ساخت بسته با خطای GPG مواجه شدید:

```bash
gpg --recv-keys <key-id>
```

مثال:

```bash
gpg --recv-keys 3056513887B78AEB
```

### ۲. **خطای دسترسی یا مجوز**

اگر با خطای دسترسی به فایل‌های `yay` مواجه شدید، مطمئن شوید مالکیت پوشه cache به کاربر فعلی تعلق دارد:

```bash
sudo chown -R $USER:$USER ~/.cache/yay
```

### ۳. **پاکسازی cache اضافی**

برای آزادسازی فضا و حذف بسته‌های بلااستفاده:

```bash
yay -Sc
```
